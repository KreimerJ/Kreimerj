## 🛠️ Featured Technical Projects

### 🌟 [Static Site Generator](https://github.com/KreimerJ/static_site_generator) *(Boot.dev Guided Project)*
> A zero-dependency Static Site Generator built in Python following the Boot.dev backend curriculum.
- Converts Markdown hierarchies into static HTML websites using an Abstract Syntax Tree (AST) node pipeline (`LeafNode`, `ParentNode`).
- Includes regex-based inline tokenizers with negative lookbehind, block-level parsers, recursive directory crawler, asset synchronization, and GitHub Pages deployment.
- **Coverage:** 6 comprehensive `unittest` test suites covering all node structures and parsers.
- **Live Demo:** [KreimerJ.github.io/static_site_generator](https://KreimerJ.github.io/static_site_generator/)

### 🤖 [AI Tool-Calling Agent](https://github.com/KreimerJ/ai_agent_python) *(Boot.dev Guided Project)*
> An automated CLI agent loop built in Python with the OpenAI SDK and OpenRouter.
- Executes dynamic tool calling with JSON schema validation and sandboxed file-system operations (`get_files_info`, `run_python_file`, `write_file`).
- Tracks token usage metrics and enforces an iteration limit safeguard to prevent runaway loops.
- Tested with dedicated unit tests across all tool functions.
